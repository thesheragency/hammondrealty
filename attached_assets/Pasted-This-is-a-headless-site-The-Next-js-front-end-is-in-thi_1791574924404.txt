Last round of mobile speed fixes for /home-prep-program. The previous changes worked: on a real throttled phone test (slow 4G, empty cache) the hero now shows at about 2.7 s, down from 6.2 s. PageSpeed mobile is 67. What's left is the critical path:

1. Render-blocking CSS (biggest remaining item). The main stylesheet /_next/static/chunks/e60d42d91f6c7587.css is about 124 KB uncompressed and blocks the first paint. On slow 4G it takes about 2.4 s to load, and the hero image downloads in parallel and competes with it.
   - Remove unused CSS: check that Tailwind's content paths only cover files that are actually used, and that no full CSS bundles from libraries (carousel/slider/animation libraries, unused component styles) are imported globally. Import component CSS only where the component is used.
   - Then enable CSS inlining for the first paint, so the page doesn't wait for a separate CSS request: use Next's experimental.inlineCss (Next 15+) or critical CSS inlining (experimental.optimizeCss), whichever this Next version supports. If it causes any visual difference or flash of unstyled content, revert it and tell me.

2. Fonts: two web fonts (~38 KB and ~48 KB) are preloaded at the highest priority and compete with the hero image.
